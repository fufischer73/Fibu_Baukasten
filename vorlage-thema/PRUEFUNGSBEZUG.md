# Prüfungsbezug: Wie die prüfungsnahen Aufgaben im Pfad berücksichtigt werden

Grundlage: <prüfungsnahe Aufgaben der Lehrkraft, Quelle und Zeitraum eintragen>. Die Aufgaben sind **nur Stilvorlage**, es wird keine Aufgabe nachgebaut. Alle Belege und Zahlen im Pfad sind eigene.

## Aufgabenarten der Prüfung und ihre Umsetzung

| Aufgabenart in der Prüfung | Beispiele (Nr.) | Umsetzung im Pfad | Stand |
| --- | --- | --- | --- |
| **Kontieren** (Konten ankreuzen) | | Nicht als Ankreuzen, sondern als **Buchungssatz bilden** mit denselben Ablenkern. Im Test zusätzlich als Multiple Choice mit Beleg. | |
| **Sachverhalt beurteilen** (Multiple Choice, mehrere Aussagen) | | Prüfungsstil-Aufgaben mit dem Operator „Prüfe“ bzw. „Beurteile“. | |
| **Berechnen** (Zahl eingeben) | | Rechenfelder mit Zahlen im Beleg-Stil, Parallelaufgaben. | |
| **Beleg lesen** | | Alle Aufgaben arbeiten mit echten Belegen. | |
| **Operatoren** der Aufgabenstellung | | In der Überprüfung verwenden die Aufgaben die Operatoren der Prüfung. | |
| **Offene Frage / Beurteilen** | | Eine offene Frage im Abschlusstest, von Hand bewertet. | |
